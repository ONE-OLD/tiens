# TIENS! — Web Application

A web application project for TIENS! Ltd., with account access pages and supporting site content.

## Current structure

- Login and signup pages
- Password recovery page
- Shared authentication styles and JavaScript
- Main application pages and image assets
- A project style guide

## Technology

- HTML5
- CSS3
- JavaScript modules
- Firebase Authentication

## Run locally

Clone the repository and serve the project through a local web server. Review the Firebase configuration in `common.js` and related authentication scripts before testing.
